# 🚀 RaceTech - Responsive Business Website

Netlify Link: https://racetech-bootstrap.netlify.app/

Site Link : https://rohini-pr.github.io/RaceTech-bootstrap-website/


## About the Project

RaceTech is a modern and fully responsive business website developed using **HTML5**, **CSS3**, and **Bootstrap 5**. The website is designed with a clean and professional interface to showcase a company's services, portfolio, and business information while providing an intuitive user experience across all devices.

The project demonstrates the effective use of Bootstrap's responsive layout system and UI components to build a visually appealing and mobile-friendly website.

## ✨ Features

- Responsive Navigation Bar
- Hero/Header section using Bootstrap Grid
- Client section using Flexbox (`d-flex` and `flex-wrap`)
- Services section with Bootstrap Cards and Grid
- About section with responsive Grid layout
- Portfolio section using Bootstrap Cards
- FAQ section using Bootstrap Accordion
- Responsive Footer with copyright information

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5

## 📚 Bootstrap Components Used

- Navbar
- Grid System
- Cards
- Flex Utilities (`d-flex`, `flex-wrap`)
- Accordion
- Buttons

## 🎯 Purpose

This project was created to practice responsive web design and strengthen front-end development skills by implementing Bootstrap's layout system, components, and utility classes. It demonstrates how to build a professional business website with a responsive and user-friendly interface.
